## 📌 Proje Hakkında

**KOKU{KODU}**, kullanıcıların lüks ve niş parfüm modellerinin yerli üreticilerdeki (Bargello, Mad Parfüm, Muscent, David Walker vb.) muadil kodlarını anında sorgulayabildiği, tek tıkla kopyalayıp satın alma kanallarına gidebildiği ve güncel marka indirim kuponlarına ulaşabildiği yüksek performanslı bir web aracıdır.

---

## ⚡ Temel Özellikler

* 🔍 **Anlık Arama Motoru:** Parfüm adı, marka veya muadil koduna göre sıfır gecikmeli istemci taraflı filtreleme.
* 📋 **Akıllı Pano (Clipboard):** Muadil kodlarını tek dokunuşla panoya kopyalama ve toast bildirim sistemi.
* 🎟️ **Dinamik Kupon Alanı:** Supabase REST API üzerinden beslenen anlık ve aktif indirim kuponları modalı.
* 🌓 **Çift Tema Desteği:** `localStorage` kalıcı hafızalı Koyu (Dark) ve Açık (Light) mod seçeneği.
* 💼 **B2B Sponsorluk Altyapısı:** Öne çıkan sponsorlu ürün listeleme ve marka iletişim kanalları entegrasyonu.
* 📱 **Tam Responsive Tasarım:** Masaüstü, tablet ve mobil cihazlar için optimize edilmiş minimalist UI/UX.

---

## 🛠️ Teknoloji Yığını

* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (Modern Flex/Grid Mimarisi, CSS Değişkenleri)
* **Backend & Veritabanı:** [Supabase](https://supabase.com) (PostgreSQL / PostgREST)
* **Barındırma & Dağıtım:** [Vercel](https://vercel.com)
* **Tipografi:** Plus Jakarta Sans, JetBrains Mono
